## Rules

Strict TS, no `any`, `import type`, Prettier (no semicolons, single quotes, width 100). Components under ~200 lines. Every data view: skeleton, `EmptyState`, `ErrorState`. Mobile-first; nothing wider than the viewport at 320 px (tables → `DataTable` with `mobileCard`, long toolbars wrap, dialogs `max-h-[90dvh] overflow-y-auto`). Touch targets ≥ 44 px on mobile. Text + colour for status. Tests for every new domain function and at least one integration test per page. Finish with `npx prettier --write <files>`, `npx tsc -b --noEmit 2>&1 | grep -E "<your paths>"`, `npx eslint <files>`, `npx vitest run <your test paths>`. Dev server for this app: http://localhost:5174 (never 5173). Do not run `npm install`.
